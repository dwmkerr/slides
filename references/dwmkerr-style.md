# dwmkerr.com style

Use this style for personal, technical, and coding-agent decks.

## Visual language

- Warm off-white canvas: `#f4f0e8`
- Near-black ink: `#171717`
- Amber accent: `#d97706`
- Muted text: `#706b62`
- JetBrains Mono, SFMono-Regular, Consolas, or monospace
- A small terminal prompt or path as the eyebrow
- Fine rules, square corners, and generous empty space

## Layouts

- Cover: small terminal eyebrow, large lowercase title, short subhead
- Content: eyebrow, headline, one supporting block
- Two-column: equal columns separated by a fine vertical rule
- Options: numbered cards with one-sentence trade-offs
- Timeline: horizontal rule with labelled phases
- Code: high-contrast code panel with one highlighted line

Use `references/dwmkerr-com-timeline-slide.html` for the original timeline example and `themes/dwmkerr/template/presentation.html` for a complete multi-slide deck.
