Features

Edit

Press E to edit text. When the deck is served, changes save to the HTML file.

Comment

Press C to leave a comment for your agent.

Themes

Add a <style data-slides-theme> block for each theme and the menu shows a toggle.

Print

Print from the browser to get one 16:9 page per slide.

Check

slides check deck.html reports broken assets and slides that overflow.

Export

slides export deck.html --slides 1,3-5 exports selected slides to PDF.
